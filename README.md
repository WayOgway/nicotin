# Лендинг: освобождение от никотиновой зависимости

Одностраничный сайт соматического практика. Статический: HTML + CSS + JS,
без сборки и зависимостей. Открывается как файл, заливается на любой хостинг.

```
nicotine-free/
├─ index.html            ← лендинг: весь контент
├─ terms.html            ← договор и условия гарантии
├─ assets/
│  ├─ css/style.css      ← оформление и адаптив
│  ├─ js/main.js         ← меню, анимации, FAQ, калькулятор, согласие
│  └─ img/
│     ├─ author.jpg      ← фото автора (900×1351)
│     └─ og.jpg          ← картинка для соцсетей (1200×630)
├─ serve.ps1             ← локальный просмотр (Windows)
└─ README.md
```

---

## 1. Локальный просмотр

powershell -ExecutionPolicy Bypass -File .\serve.ps1

## 4. Договор, гарантия и согласие

### 4.1. Гарантия

Гарантия — **доведение до результата в течение 12 месяцев**, а не «один
бесплатный повтор». Обычно достаточно одного сеанса; если время ограничено или
задача глубже — от двух до пяти. Число сеансов не ограничено жёстко, ограничен
срок.

Возврат денег не предусмотрен: это осознанное условие, зафиксированное в
договоре. Психика может использовать возможность возврата, чтобы обесценить и
перечеркнуть даже стабильный результат.

Тексты гарантии находятся в:

- `index.html` — секция `#guarantee` и FAQ;
- `terms.html` — разделы 4–7 (результат, гарантия, когда действует, когда нет,
  возврат средств).

### 4.2. Что обязательно проверить в договоре

- Статус: в договоре указано «физическое лицо, частная практика», потому что
  ИП или самозанятость пока не оформлены. Когда оформите — обновите разделы 1
  и 11 в `terms.html`: добавьте статус, ИНН и ОГРНИП (если ИП).
- Длительность сеанса «от одного до полутора часов» — в `terms.html`, раздел 2,
  и в `index.html`, секция `#method`. Если изменится, поправьте оба места.
- Количество сеансов 1–5 — в `#guarantee`, FAQ и `terms.html`. Число не жёсткое:
  в договоре указано, что при необходимости график согласуется, а срок ограничен
  12 месяцами.
- Условия отмены и переноса — `terms.html`, раздел 3.
- Противопоказания — `terms.html`, раздел 6. При необходимости согласуйте
  формулировки с юристом.

### 4.3. Галочка согласия

В результате калькулятора есть чекбокс:

> С условиями и договором ознакомлен(а) и согласен(на). Понимаю, что возврат
> средств не предусмотрен.

Кнопка «Скопировать и открыть Telegram» по умолчанию `disabled`. Она становится
активной только после галочки. Логика — в `assets/js/main.js`, блок

Без JavaScript кнопка не работает — для этого добавлено `<noscript>` с прямой
ссылкой на Telegram.

## 5. Калькулятор

Формула:

```
стоимость сеанса = траты на никотин в день × 30
```

Два режима:

- **«По пачкам»** — цена пачки × количество в день.
- **«Сумма в день»** — сразу сумма трат за день (удобно для вейпа и стиков).

В обоих случаях показываются траты в день, в год и окупаемость сеанса (30 дней).
Ниже — готовая фраза «Вы не платите больше, чем уже тратите» и сообщение с
приветствием, суммой трат в день и ценой сеанса. Его можно скопировать отдельно
или кнопкой «Скопировать и открыть Telegram»: текст попадёт в буфер, чат
откроется в новой вкладке — останется вставить сообщение.

Если захотите менять срок (30 дней) или добавлять другие валюты — это
константы `DAYS` и `YEAR_DAYS` в `assets/js/main.js`, а также текст «30 дней»
в `index.html`.

## 6. Яндекс.Метрика: пошагово

1. Зайдите на [metrika.yandex.ru](https://metrika.yandex.ru) под своим Яндекс ID.
2. **«Добавить счётчик»**.
3. Название: `nicotine-free`. Сайт: адрес после публикации (например,
   `https://vash-domen.ru`). Если сайта ещё нет — поставьте любой, потом
   измените.
4. Включите **«Вебвизор»**, **«Карта скроллинга»**, **«Аналитика форм»** —
   они бесплатны и показывают, где люди останавливаются.
5. Часовой пояс — Москва. Нажмите **«Создать счётчик»**.
6. Скопируйте код счётчика. В `index.html` найдите комментарий:

   ```html
   <!-- Яндекс.Метрика: вставьте сюда код счётчика. Пошаговая инструкция — в README, раздел 6. -->
   ```

   и вставьте код **вместо** этого комментария (перед `</head>`).
7. Откройте сайт, обновите страницу. В Метрике → «Счётчики» статус должен
   стать «Работает».
8. **Цели.** В настройках счётчика → «Цели» → «Добавить цель»:
   - `Калькулятор` — тип «Просмотр страницы», условие: URL содержит `#calc`.
   - `Согласие с договором` — тип «JavaScript-событие», идентификатор
     `consent_given`.
   - `Клик по записи` — тип «JavaScript-событие», идентификатор `booking_click`.
   - `Копирование сообщения` — тип «JavaScript-событие», идентификатор `message_copied`.
9. В `assets/js/main.js` найдите:

   ```js
   metrikaId: null
   ```

   и замените `null` на номер счётчика, например `metrikaId: 12345678`.
   Вызовы целей уже встроены: `consent_given` отправляется при галочке,
   `booking_click` — при нажатии на кнопку записи, `message_copied` — при
   копировании сообщения. Пока стоит `null`, ничего не отправляется.
10. Через 1–2 дня проверьте отчёты: «Источники», «Вебвизор», «Цели».

Если не хотите менять JS — настройте хотя бы цель по URL `#calc`: этого уже
достаточно, чтобы видеть, сколько людей дошли до расчёта.

## 7. Open Graph и соцсети

Картинка для превью: `assets/img/og.jpg` (1200×630). В `index.html` прописаны
абсолютные адреса, привязанные к текущему домену:

```html
<meta property="og:url" content="https://wayogway.github.io/nicotin/">
<meta property="og:image" content="https://wayogway.github.io/nicotin/assets/img/og.jpg">
<meta name="twitter:image" content="https://wayogway.github.io/nicotin/assets/img/og.jpg">
<link rel="canonical" href="https://wayogway.github.io/nicotin/">
```

**Если домен сменится** — замените `https://wayogway.github.io/nicotin/` на новый
адрес в этих четырёх строках. Относительный путь соцсети не понимают и картинку
не покажут.

Проверка превью:

- Telegram — отправить ссылку в «Избранное» (может закэшироваться; помогает
  `?v=2` в конце ссылки).
- Facebook — [developers.facebook.com/tools/debug](https://developers.facebook.com/tools/debug/).
- VK — [vk.com/dev/pages.clearCache](https://vk.com/dev/pages.clearCache).

Как обновить сайт после правок:

```powershell
cd nicotine-free
git add -A
git commit -m "правки"
git push
```

GitHub Pages пересобирает сайт за 30–60 секунд.

Другие варианты, если понадобится:

- **Netlify** — [app.netlify.com/drop](https://app.netlify.com/drop), перетащить папку.
- **Хостинг (Timeweb, Beget)** — файлы по FTP в `public_html`.
- **Vercel** — перетащить папку в панели.

После публикации:

1. Проверьте кнопки «Рассчитать», галочку и переход в Telegram.
2. Откройте сайт на телефоне.
3. Вставьте код Метрики и настройте цели.
4. Проверьте `terms.html`: ссылки, реквизиты, дату редакции.
